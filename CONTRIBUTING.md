# Contributing

Contributions are welcome when they preserve research integrity and safe defaults.

1. Create a focused branch and explain the research or engineering reason for the change.
2. Use only synthetic examples.
3. Run dataset validation and the full test suite.
4. Add tests for scoring or adapter changes.
5. Do not mark a translation approved unless a named bilingual reviewer completed the review checklist.
6. Do not submit generated results as empirical evidence without immutable run manifests and version-pinned configurations.
