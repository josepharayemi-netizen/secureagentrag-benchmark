# Ethics and responsible research

SecureAgentRAG uses synthetic data, isolated test environments and reversible simulated actions. It does not require real personal data, production credentials or tools that can change real accounts.

Human language reviewers must provide informed consent and receive appropriate credit. Published results must disclose provider credits, financial or organizational conflicts, failed runs, missing data, material protocol changes and post-hoc analyses.

Attack details should be released only when they support reproducibility without creating a material operational risk. Otherwise, publish the category, expected behavior and scoring label rather than actionable exploit instructions.
