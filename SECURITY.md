# Security policy

Use only dedicated test accounts, least-privilege identities, synthetic corpora and inert tools. Never commit API keys, cloud credentials, private endpoints, production identifiers or customer data.

The example provider files contain placeholders and are not live integrations. Real adapters must enforce timeouts, rate limits, audit logging, output sanitization and explicit confirmation for high-impact actions.

Please report a vulnerability privately to `yemi@giitafrica.com`. Do not include live credentials or real personal data in a report.
